GitStat · free public dashboard

See where your engineering effort is actually going.

GitStat is for developers managing more repositories than a contribution graph can explain. Enter any GitHub username to inspect how effort, code churn, collaboration, pull requests, issues, and sampled AI involvement are distributed across a public footprint. No account or payment is required.

Analytics that stay separate

GitStat keeps commits, additions, deletions, net change, repository concentration, languages, cadence, collaboration, pull requests, issues, inactivity gaps, and AI signals in distinct views. It does not compress them into a single productivity score, and the dashboard keeps links to the underlying public repositories.

Current access and data boundary

The current product analyzes public GitHub data only; the earlier optional OAuth and private-repository connection is not exposed. GitHub responses are processed in the browser and cached on this device for one hour. GitStat has no user account store, paid tier, checkout, or product analytics tracking. AI involvement is inferred from sampled public commit metadata and is not proof of authorship.

What happens after a username is submitted

The dashboard discovers public personal and organization repositories, reads contribution statistics with retry handling, and progressively fills the analysis views. Time-period filters and generated-file exclusions remain adjustable. Large footprints can take longer or wait for the shared GitHub API allowance to reset; that operational limit is shown instead of being hidden behind an invented premium plan.
