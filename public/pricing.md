# GitStat pricing and availability

GitStat is free to use for public GitHub analysis. There is no subscription, checkout, token pack, licence purchase, or paid tier in the current product.

The public dashboard uses a shared GitHub API allowance, so large analyses may occasionally need to wait for rate-limit reset. Paying GitStat does not increase that limit because GitStat does not currently sell access.
